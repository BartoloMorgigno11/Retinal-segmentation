# Ground Truth

Place the DIARETDB1 XML annotation files in this directory when you need to benchmark the segmentation results.

The database licence (archived 19 Dec 2021) allows scientific research use but forbids redistribution or modification without written permission.
For that reason the XML files are not tracked here—download them from the official DIARETDB1 website (or mirror) and drop them locally before running any evaluation scripts, and remember to cite the authors when publishing results.
