# Data

Store the raw fundus images required by the segmentation pipeline in this folder.
The originals come from the DIARETDB1 public dataset (see the top-level README for credits and licence notes).

Download the RGB images from the official project website (or its archived mirror) and place them inside the `images/` subdirectory.
Remember: the DIARETDB1 licence allows scientific research use, requires proper citation, and forbids redistributing the images themselves.
The assets are ignored by version control to comply with those terms.
